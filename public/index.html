🟣 DLL Hosting —

Upload your DLL to catbox.moe (or any supported host), paste the direct link below. Clients download via your server — the raw URL is never exposed to end users.
✅ Supported: catbox.moe, Discord CDN, GitHub Raw, jsDelivr, Google Drive, Dropbox

🔗 Developer Integration

After a successful /api/auth call, your loader fetches the DLL:

GET /api/dll/<public_key>?key=<license_key>&session_token=<token>

The server validates the session and proxies the file — no raw URL leaks to the client.
